# Skill: HTML/CSS/JS Presentation Engine

Ты — опытный frontend-разработчик, создающий презентации на чистых веб-технологиях.

## Цель

Создать презентацию, которая запускается открытием `index.html` (локально или через HTTP-сервер) и работает без сборщиков, npm и сторонних библиотек.

Используются только:

- HTML
- CSS
- JavaScript
- современные Web API

## Основные требования

### Структура

Каждый слайд представляет собой отдельную секцию.

```html
<body>
    <main class="slides">
        <section>
            ...
        </section>

        <section>
            ...
        </section>

        <section>
            ...
        </section>
    </main>
</body>
```

Каждый `<section>` — полноценный экран.

### Формат презентации
Соотношение сторон:

**16:9**

Каждый слайд занимает весь экран браузера.

При изменении размера окна презентация должна адаптироваться.

Отправной размер 1920x1080

### Навигация

Используется вертикальный скролл.

Обязательно применять:

- CSS Scroll Snap
- плавную прокрутку
- колесо мыши
- touch-жесты
- клавиши:

```
↓
↑
PageDown
PageUp
Space
```

Переход всегда происходит ровно на следующий или предыдущий слайд.

### Scroll Driven Animations

Использовать только современные CSS Scroll-Driven Animations.

Применять:

- `animation-timeline`
- `view-timeline`
- `scroll-timeline`

Никаких JS-анимаций, если задача может быть решена через CSS.

### Прогресс-бар

В нижней части страницы расположен progress bar.

Он показывает прогресс просмотра презентации.

Используется исключительно Scroll Timeline.

Запрещается вычислять прогресс через JavaScript.

## Переключение страниц
В адресной строке добавь get-атрибут currentSlides, который отображает текущий слайд
В адресной строке можно сменить число на другое, тогда будет плавная прокрутка до нужного слайда.
Плавность прокрутки достигается с помощью `scroll-behavior: smooth`

### Счетчик слайдов
Использовать CSS Counter.
Например:

```
1

2

3
```

Количество слайдов должно вычисляться автоматически.
Без JavaScript.


### Анимация появления
Контент каждого слайда появляется при входе слайда во viewport.
Использовать View Timeline.

Например:

- fade
- slide
- scale

### Производительность

Использовать:
- transform
- opacity

Избегать:
- top
- left
- width
- height

Анимации должны быть GPU-friendly.

### JavaScript
JS используется только для:

- клавиатурной навигации
- перехода между слайдами
- служебной логики

Не использовать JS для:

- анимаций
- прогресс-бара
- счетчиков
- вычисления положения элементов


### Архитектура проекта

```
/
├── index.html
├── style.css
├── script.js
└── assets/
```


### Стиль кода

HTML:
- семантическая разметка
- минимум лишних div

CSS:
- современные возможности CSS
- CSS Custom Properties
- логические свойства
- CSS Nesting (при необходимости)
- современные единицы (`dvh`, `cqw`, `cqh` и др., где уместно)

JavaScript:
- ES Modules (если требуется)
- без сторонних библиотек
- современный синтаксис ES2024+

### Совместимость
Ориентироваться на последние версии:
- Chrome

Разрешается использовать только современные API.
Не требуется поддержка старых браузеров.

### Внешний вид
Каждый слайд занимает всю область просмотра.

Поддерживаются:
- изображения
- видео
- код
- списки
- таблицы
- SVG
- Canvas

## Принципы
Предпочитать:
1. CSS вместо JavaScript
2. Нативные Web API вместо библиотек
3. Современные стандарты платформы
4. Простую архитектуру без зависимостей
Если задачу можно решить средствами CSS, не использовать JavaScript.
При генерации кода всегда придерживаться этих правил.

## PDF
Добавь pdf-генератор с помощью команды npm run pdf
pdf-файл не добавляй в гитигнор, чтобы его могли скачать в репозитории
В pdf файле должны отображаться шрифты и фоны из презентации
