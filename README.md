# WebMCP / Scrolls

HTML-презентация на 20 слайдов: **1–10 — WebMCP**, **11–20 — универсальные макеты**.

Откройте `index.html` в актуальном Chrome. Интернет, npm install и сборка не нужны.
Для локального HTTP-сервера (Node.js 20+):

```sh
npm start
```

Адрес: http://localhost:4173. Другой порт: `PORT=8080 npm start`.

## Навигация

- ↓, PageDown, Space — следующий слайд.
- ↑, PageUp, Shift + Space — предыдущий.
- Home / End — первый / последний.
- Трекпад, колесо и свайп — нативная прокрутка с CSS Scroll Snap, без перехвата жестов в JavaScript.
- Cmd + K — показать / скрыть toolbar в обычном и полноэкранном режиме. По умолчанию toolbar виден; при каждом входе в fullscreen скрывается. При выходе восстанавливается выбранная видимость обычного режима.
- M — оглавление, G — сетка из 12 колонок, F — полный экран, ? — справка.
- `?currentSlides=11` открывает библиотеку макетов. Нумерация начинается с 1.
- Параметр обновляется при переходах. Прямые ссылки и история браузера поддерживаются.
- Esc закрывает оглавление или справку. В режиме reduced motion прокрутка и появление без движения.

На широком экране canvas сохраняет **16:9** и масштабируется целиком. На портретном экране композиции адаптируются к высоте окна. PDF всегда остаётся 16:9.

## PDF

```sh
npm run pdf
```

Результат: [`output/pdf/webmcp-presentation.pdf`](output/pdf/webmcp-presentation.pdf).
Файл **не исключён из Git**. Экспорт использует установленный Chrome/Chromium и временный профиль, не затрагивая пользовательский профиль браузера. Можно задать `CHROME_PATH` или другой путь результата:

```sh
CHROME_PATH=/path/to/chrome npm run pdf
npm run pdf -- output/pdf/custom-name.pdf
```

Печать сохраняет фоны, встроенные шрифты, подсветку кода и ссылки. Анимации, сетка и элементы управления отключаются. Системный шрифт в PDF соответствует системе, на которой выполнен экспорт.

## Изменение слайдов

Скопируйте подходящий `<section class="slide ...">` внутри `.slides`. Укажите уникальные `id`, `aria-labelledby`, ID заголовка и подписи `data-part` / `data-layout`. Слайды остаются статическим HTML и читаются без JS. Блок кода: `<pre class="code"><code data-language="javascript">…</code></pre>`; поддерживаются JavaScript и HTML. В HTML-примерах экранируйте `<` как `&lt;`.

Порядок секций задаёт порядок показа. Текущий номер использует **CSS Counter** с ведущим нулём (`03`), без общего количества и без JS.

`style.css` содержит темы, композиции, печать, `scroll-timeline` для прогресса и `view-timeline` для появления. `script.js` отвечает за навигацию, URL, справку, сетку и безопасную подсветку через текстовые узлы. JS не вычисляет позиции элементов и прогресс. Плавная прокрутка задаётся `scroll-behavior`, текущий слайд для URL отслеживается через `IntersectionObserver`. Обработчиков `wheel`, `touch` и `scroll` нет. Целевая платформа — актуальный Chrome с CSS Scroll-Driven Animations.

Изображения и видео добавляются в `<figure>` внутри макета `.layout-media`. SVG и Canvas можно вставлять непосредственно в HTML; внешних медиазависимостей в этой презентации нет.

## Источники WebMCP

Проверены 5 сентября 2026 года. WebMCP развивается; это draft Community Group, а не стандарт W3C. Код иллюстрирует API спецификации от 4 сентября 2026 года (`document.modelContext`); ранние реализации preview используют `navigator.modelContext`. Примеры на слайдах показываются как текст и не регистрируют инструменты в браузере.

- [WebMCP specification](https://webmachinelearning.github.io/webmcp/) — API, статус и безопасность.
- [WebMCP explainer](https://github.com/webmachinelearning/webmcp/blob/main/README.md) — модель взаимодействия.
- [Declarative API explainer](https://github.com/webmachinelearning/webmcp/blob/main/declarative-api-explainer.md) — атрибуты форм.
- [Chrome: WebMCP early preview](https://developer.chrome.com/blog/webmcp-epp) — два API и примеры применения.

Источники также доступны по ссылкам в подвалах соответствующих слайдов.
